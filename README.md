# Fio a Fio

Repositório do projeto acadêmico Fio a Fio, separado em frontend e backend.

```text
.
├── frontend/    # protótipo HTML estático funcional
└── backend/     # espaço reservado para a futura aplicação de servidor
```

Para executar o protótipo atual, abra `frontend/public/index.html` no navegador. Veja `frontend/README.md` para a estrutura e os fluxos representados.
